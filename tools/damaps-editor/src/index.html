DaMaps Editor

Make and change maps for Da'Maps. When you're happy with a map, save it and send the .damap file to whoever looks after Lichborne's maps, so it can be added for everyone.

Tools

  • Select (V) — click a room to edit it on the right. Drag rooms to move them. Drag on empty space to select several. Shift-click adds to the selection.
  • Room (R) — click to place a room. Shift-click places one and links it to the room you had selected, so you can draw a street room by room.
  • Link (L) — drag from one room to another. That adds an exit each way, named by the direction of the drag. Hold Shift for one way only.
  • Label (T) — click to put a place name on the map.

Getting maps

  • ⇩ Latest maps (or File → Get latest maps…) downloads the official maps from Lichborne's GitHub into your map folder. A map you've changed is only replaced if you say so.
  • File → Open… opens a map from your folder. File → Import Genie map… starts from a Genie map.

Moving around

  • Mouse wheel zooms. Drag with the right or middle button (or hold Space) to move the map. F fits the map to the window.
  • Arrow keys nudge the selected rooms; Shift+arrow nudges further.
  • Del deletes the selection. Ctrl+Z / Ctrl+Y undo and redo. Ctrl+S saves.

Rooms

  • Give each room its title and description exactly as the game shows them; that's how Da'Maps finds where you are.
  • Doorway to makes a square a doorway onto another map (give that map's file name).
  • Lich room # is optional: fill it in only when Da'Maps matches the room to the wrong Lich room.
