DaMaps Editor

Make and change maps for Da'Maps. When you're happy with a map, save it and send the .damap file to whoever looks after Lichborne's maps, so it can be added for everyone.

Tools

  • Select (V) — click a room to edit it on the right. Drag rooms to move them. Drag on empty space to select several. Shift-click adds to the selection.
  • Room (R) — click to place a room. Shift-click places one and links it to the room you had selected, so you can draw a street room by room. Click the selected room again to deselect it.
  • Link (L) — drag from one room to another. That adds an exit each way, named by the direction of the drag. Hold Shift for one way only.
  • Label (T) — click to put a place name on the map.

Getting maps

  • ⇩ Latest maps (or File → Get latest maps…) downloads the official maps from Lichborne's GitHub into your map folder. A map you've changed is only replaced if you say so.
  • File → Open… opens a map from your folder. File → Import Genie map… starts from a Genie map.

Pictures

  • A link can be drawn as a Road, Dirt path, Bridge or River. Pick it in the as list before drawing links, or set it later: select two rooms (or a whole street) and choose Path between them, or use the Drawn as column in a room's exits. Linked rooms with the same surface become one smooth curve.
  • Tick Building on a room to put a roof on it. Joined rooms with the same building name share one roof shaped to all of them. Select several rooms and click Make them one building to do it at once.
  • 🖼 Picture (P) shows the picture under the rooms while you work.
  • When it looks right, click Make picture in the map's panel (click empty space to see it). The picture is saved in an art folder beside your maps, and the map remembers it. Put the .damap in the Da'Maps repository's maps folder and the picture in its art folder.
  • If you move rooms or change paths afterwards, the panel says the picture is out of date. Make it again.

Moving around

  • Mouse wheel zooms. Drag with the right or middle button (or hold Space) to move the map. F fits the map to the window.
  • Arrow keys nudge the selected rooms; Shift+arrow nudges further.
  • Del deletes the selection. Ctrl+Z / Ctrl+Y undo and redo. Ctrl+S saves.

Rooms

  • Give each room its title and description exactly as the game shows them; that's how Da'Maps finds where you are.
  • Doorway to makes a square a doorway onto another map: pick the map from the list. Open jumps to it.
  • Lich room # is optional: fill it in only when Da'Maps matches the room to the wrong Lich room.
